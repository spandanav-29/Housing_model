# House Price Prediction 🏠

**Machine Learning + PKL + Streamlit + GitHub + Cloud Deployment**

A machine learning web application that predicts median house values using a **Random Forest Regression** model trained on the historical Boston Housing dataset.

The trained machine learning pipeline is saved as a `.pkl` file and loaded into a **Streamlit** application for interactive predictions.

> **Educational Project:** This project is created for learning and demonstration purposes only. It should not be used for real-world property valuation, lending, or housing decisions.
